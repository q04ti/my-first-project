# Starbie component index

The component decisions are intentionally not final. The current verification list is maintained in [research/COMPONENTS.md](research/COMPONENTS.md), and the preliminary purchasing list is in [hardware/BOM/BOM.csv](hardware/BOM/BOM.csv).

No component should be treated as procurement-ready until its exact variant, voltage requirements, connector arrangement, and KiCad footprint have been verified.
