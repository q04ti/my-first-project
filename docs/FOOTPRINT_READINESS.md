# Starbie v1 footprint readiness

No footprint files have been copied, generated, or fabricated in this repository.

| Component | Mechanical data verified? | Footprint source | Ready for KiCad? | Remaining issue |
|---|---|---|---|---|
| XIAO ESP32-C3 | Part outline and 21 x 17.8 mm board size are documented; an official Seeed OPL KiCad footprint source exists | [Seeed OPL KiCad library](https://github.com/Seeed-Studio/OPL_Kicad_Library/tree/master/Seeed%20Studio%20XIAO%20Series%20Library) | **Conditional** | Confirm the footprint variant matches the exact purchased board, inspect pad geometry, USB edge, and antenna keepout before use |

| Adafruit MPU6050 product 3886 | Product page documents 26.0 x 17.8 mm, four 2.5 mm holes, and 0.1-inch header; product-specific Eagle board file and fab print are published | [Adafruit MPU6050 downloads](https://learn.adafruit.com/mpu6050-6-dof-accelerometer-and-gyro/downloads), [Adafruit CAD repository](https://github.com/adafruit/Adafruit-MPU6050-PCB) | **Conditional** | Confirm received board revision, header position/orientation, and mounting-hole coordinates from the fab print |

## Readiness conclusion

The DFR0067 blocker is resolved by using an external sensor and a connector-only interface; no DFR0067 module footprint is required. The project remains **not yet ready for KiCad footprint assignment** because the selected Adafruit/XIAO CAD files and the APEM switch drawing still require final revision/geometry matching.
