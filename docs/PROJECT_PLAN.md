# Starbie project plan

This plan separates planning from design, manufacturing, and physical testing. A completed phase must not be inferred from a file existing; the relevant checks must actually be performed.

## PHASE 0 — Planning

- [ ] Define features
- [ ] Define physical design
- [ ] Select components
- [ ] Create block diagram
- [ ] Create preliminary BOM

## PHASE 1 — Electronics

- [ ] Create KiCad project
- [ ] Draw schematic
- [ ] Assign symbols
- [ ] Assign footprints
- [ ] Verify electrical connections

## PHASE 2 — PCB

- [ ] Create board outline
- [ ] Place components
- [ ] Route traces
- [ ] Add ground plane
- [ ] Run DRC
- [ ] Fix all real errors
- [ ] Export Gerbers

## PHASE 3 — Firmware

- [ ] Configure Arduino IDE
- [ ] Install ESP32-C3 board support
- [ ] Install required libraries
- [ ] Implement OLED
- [ ] Implement buttons
- [ ] Implement MPU6050
- [ ] Implement DHT11
- [ ] Implement pet state
- [ ] Implement animations

## PHASE 4 — Customization

- [ ] Custom pet sprite
- [ ] Custom UI
- [ ] Custom reactions
- [ ] Sparkle/effects
- [ ] PCB artwork

## PHASE 5 — Manufacturing

- [ ] Final BOM
- [ ] Gerber verification
- [ ] PCB manufacturing
- [ ] Component procurement
- [ ] Assembly

## PHASE 6 — Testing

- [ ] Power test
- [ ] USB/programming test
- [ ] OLED test
- [ ] Button test
- [ ] MPU6050 test
- [ ] DHT11 test
- [ ] Full firmware test
- [ ] Final documentation
